💡 记忆技巧

1. 好记的不用背：1/2=50%、1/4=25%、3/4=75%、1/5=20%、2/5=40%、3/5=60%、4/5=80%、1/10=10%

2. 重点组练到 3 秒反应（最常考）

  • 1/3=33.3% → 2/3=66.7%（翻倍）
  • 1/6=16.7% → 5/6=83.3%（×5）
  • 1/7=14.3% → 2/7=28.6%、3/7=42.9%、4/7=57.1%（翻倍推导）
  • 1/8=12.5% → 3/8=37.5%、5/8=62.5%、7/8=87.5%（按 12.5% 递增）
  • 1/9=11.1%

3. 等差递减规律（从 1/11 开始，每档约减 0.6）

9.1 → 8.3 → 7.7 → 7.1 → 6.7 → 6.25 → 5.9 → 5.6 → 5.3 → 5

记住开头 9.1，后面顺着减就能推出来。

4. 特殊值单独记：1/16 = 6.25%（1/4 的一半的一半）

5. 增长量公式搭配用 ⭐

  • r = 1/n 时：增长量 = 现期 ÷ (n+1)，减少量 = 现期 ÷ (n−1)
