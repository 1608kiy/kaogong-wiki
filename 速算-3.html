r 的范围 首选方法 备用方法

一、四种方法速查对比表

方法 本质原理 适用场景 一句话口诀
化除为乘 近似公式 r<5% 的基期计算 ÷(1+r) ≈ 减，÷(1−r) ≈ 加
百化分转乘 分数等价替换 5%-30%，r 接近标准值 能乘绝不除
等比放缩 分子分母同缩放 分母接近整数；分数比较 分母凑整，分子同步
截位直除 有效数字截取 万能兜底，r>30% 或精算 分母截位，除到能区分就停

二、逐个方法详解

1️⃣ 化除为乘法（r < 5% 专属）

核心公式（必背）

类型 公式
÷(1+r) A/(1+r) ≈ A − A×r
÷(1−r) A/(1−r) ≈ A + A×r

适用场景：小增长率的基期计算，选项差距适中

例题

现期 4285，增长 3.4%，求基期。

4285 ÷ (1 + 3.4%) ≈ 4285 − 4285×3.4% ≈ 4139 ✅

⚠️ 注意：只适用于 |r| < 5%，r 越大误差越大！

2️⃣ 百化分转乘法（5% ≤ r ≤ 30% 首选）⭐

核心要点

  • 把分母 1±r 转化为分数，除法变乘法，能乘绝不除
  • 结果微调原则：分母比标准值大 → 结果略小；分母比标准值小 → 结果略大

例题

现期 4192，降幅 19.06%，求基期。

步骤 内容
① 找接近标准值 19.06% ≈ 20% → ÷0.8 ≈ ×1.25
② 转乘计算 4192 × 1.25 = 5240
③ 误差微调 真实分母 0.8094 大于 0.8 → 结果略小于 5240 ≈ 5180 ✅

3️⃣ 等比放缩法（分母凑整辅助）

核心要点

  • 分子分母按相同比例缩放，分数值不变
  • 把分母凑成整数 / 好算的数，简化计算

适用场景：5%-30% 区间，分母接近整十数；多用于分数比较（精算速度弱于截位直除）

例题

4192 ÷ 0.8094

分母缩小约 1% 凑成 0.8，分子同步缩小 1%
≈ 4150 ÷ 0.8 = 5187.5 ✅

4️⃣ 截位直除法（万能兜底）🛡️

核心要点

  • 分母截有效数字，分子不动
  • 除到能区分选项就停，不用除完
选项差距 分母截位
差距大（>10%） 截 2 位
差距小（<10%） 截 3 位

适用场景：所有除法题型，尤其 r>30%、选项差距小的精算

例题

31325 ÷ 0.9266，选项差距小

分母截 3 位：0.9266 → 0.927
31325 ÷ 927 ≈ 33.8xx（即 338xx）✅

5️⃣ 多步除法（连除/叠除）

核心要点

  • 先交叉约分整理成 (A×D)/(B×C)，再分别截位计算

适用场景：基期比重、基期倍数、平均数的倍数等题型

例题

1234/1.12 ÷ 2345/1.08
= (1234 × 1.08)/(2345 × 1.12)
≈ 0.52 ✅

三、⚠️ 易错提醒

方法 常见坑
化除为乘 只能用于 r<5%；r 大了误差失控
百化分 别记混方向：÷0.8 是 ×1.25（变大），÷1.25 是 ×0.8（变小）；30% 无友好分数
等比放缩 分子分母必须同方向同比例缩放
截位直除 只截分母不截分子；差距判断错会导致截位不够精
多步除法 交叉约分别搞反：除以分数 = 乘它的倒数

四、📌 做题思考顺序（核心思路）

看到除法计算
    │
    ▼
第一步：看选项差距
    （决定能估多粗：差距大→2位截/大胆估；差距小→3位截/精算）
    │
    ▼
第二步：看 r 落在哪个区间
    ├─ r < 5%
    │      → 化除为乘（A ÷ (1+r) ≈ A − A×r）
    │
    ├─ 5% ≤ r ≤ 30%
    │      ├─ r 接近标准值（10%、12.5%、20%…）
    │      │      → ⭐ 百化分转乘法（能乘绝不除）
    │      │         算完记得按真实分母微调方向！
    │      ├─ 分母接近整数 → 等比放缩
    │      └─ 都不凑整 → 截位直除
    │
    └─ r > 30%
           → 截位直除兜底
    │
    ▼
第三步：多步除法？
    → 先交叉约分成 (A×D)/(B×C)，再按上面规则逐个处理

💡 思考三连问

  1. 选项差多少？ → 决定估算精度（截几位）
  2. r 是多少？ → 决定用哪条路径（<5% 化乘 / 5-30% 百化分 / >30% 直除）
  3. 结果偏哪边？ → 百化分和估算后，必须判断真实值偏大还是偏小，防止选错
