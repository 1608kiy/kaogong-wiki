## 一、三种方法速查对比表

| **方法**    | **适用场景**   | **选项特征** | **核心做法**          | **一句话口诀** |
| --------- | ---------- | -------- | ----------------- | --------- |
| **尾数法**   | 加减法运算      | 末位/末两位不同 | 只算末尾1-2位加减，尾数匹配选项 | 只算尾数，直接锁定 |
| **凑整法**   | 数字接近整十/百/千 | 不限       | 先凑整再加减，多退少补       | 凑整计算，多退少补 |
| **高位叠加法** | 多位数加法      | 首位/前两位不同 | 高位→低位逐位加，能区分即停    | 高位起算，边算边选 |

## 二、逐个方法详解

### 1️⃣ 尾数法

**核心要点**

* 适用：选项末位 / 末两位数字不同
* 做法：只计算数字末尾 1-2 位的加减，用得数尾数直接匹配选项

**例题**

> 计算：1256.8 + 3407.5 + 2189.2 + 1674.6
> A. 8528.1  B. 8613.7  C. 8702.4  D. 8891.3

**解题过程**

| **步骤** | **内容**                         |
| ------ | ------------------------------ |
| ① 看选项  | 末位小数各不相同 → 只算末位                |
| ② 算尾数  | 8 + 5 + 2 + 6 = 21 → 尾数为 **1** |
| ③ 锁定答案 | 选 **A（8528.1）** ✅              |

***

### 2️⃣ 凑整法

**核心要点**

* 适用：数字接近整十 / 整百 / 整千
* 做法：先凑成整数再加减，多算的减掉、少算的补上（**多退少补**）

**例题**

> 计算：7642 − 2995 + 1998 − 3007

**解题过程**

原式 = 7642 − (3000−5) + (2000−2) − (3000+7)

\= 7642 − 3000 + 5 + 2000 − 2 − 3000 − 7

\= 7642 − 4000 − 4

\= 3638

| **拆解**      | **调整方向** | **修正** |
| ----------- | -------- | ------ |
| 2995 → 3000 | 多减了 5    | +5 补回  |
| 1998 → 2000 | 多加了 2    | −2 减掉  |
| 3007 → 3000 | 少减了 7    | −7 补减  |

***

### 3️⃣ 高位叠加法

**核心要点**

* 适用：多位数加法、选项首位 / 前两位不同
* 做法：从左往右（高位→低位）依次相加，边算边匹配选项，**能区分答案就停，不用算完**

**例题**

> 计算：2389 + 4567 + 1724 + 3105
> A. 10785  B. 11785  C. 12785  D. 13785

**解题过程**

| **步骤** | **计算**                       | **结果**                     |
| ------ | ---------------------------- | -------------------------- |
| ① 千位   | 2 + 4 + 1 + 3 = 10           | 首位为 10                     |
| ② 百位   | 3 + 5 + 7 + 1 = 16 → 写 6 进 1 | 前两位为 **11**                |
| ③ 匹配选项 | 前两位 11 → 对应 B                | 选 **B（11785）** ✅（十位个位无需再算） |

***

## 三、⚠️ 易错提醒

| **方法** | **常见坑**                        |
| ------ | ------------------------------ |
| 尾数法    | 数位要对齐，缺位补 0；减法注意借位             |
| 凑整法    | 拆数后符号要跟着变（如 −2995 = −3000 + 5） |
| 高位叠加法  | 别忘进位！进位会改变前一位结果                |

***

## 四、📌 做题流程（复习要点）

看到加减法 → 先看选项

├─ 末位不同 → 尾数法

├─ 首位不同 → 高位叠加法

└─ 数字近整 → 凑整法

> 💡 **核心习惯**：先看选项，再选方法，不要上来就硬算！

# 📊 资料分析 · 乘法速算 完整笔记

## 一、三种方法速查对比表

| **方法**     | **本质原理**        | **适用场景**                       | **选项特征**  | **一句话口诀**       |
| ---------- | --------------- | ------------------------------ | --------- | --------------- |
| **错位加减速算** | 乘法分配律（本身±本身×比例） | r 为规整百分数（10%、20%、50%…）；增速/降幅判定 | 差距适中      | ×1.1错位加，×0.9错位减 |
| **拆分法**    | 乘法分配律（整数+零头）    | 乘数不规整、需要精算                     | 差距小（\<5%） | 拆成整数加零头，分开乘再合并  |
| **凑整估算法**  | 四舍五入凑整          | 只需判断范围、不需精算                    | 差距大（>10%） | 凑整先算，误差再调       |

***

## 二、逐个方法详解

### 1️⃣ 错位加减速算（⭐资料分析最常用）

**核心要点**

* 用「本身 ± 本身的比例」替代乘法，本质是**乘法分配律**
* 对应资料分析核心公式：**基期 × (1+r) = 现期**

**常用固定倍率表（必背！）**

| **乘数** | **转化**      | **记忆方式**  | **对应含义** |
| ------ | ----------- | --------- | -------- |
| ×1.1   | 本身 + 本身×0.1 | 错位加一位     | 增速 10%   |
| ×0.9   | 本身 − 本身×0.1 | 错位减一位     | 降幅 10%   |
| ×1.2   | 本身 + 本身×0.2 | 加本身的 20%  | 增速 20%   |
| ×1.5   | 本身 + 本身×0.5 | **加自身一半** | 增速 50%   |

**适用场景**

* 增速/降幅是否超标的**判定题**
* r 为规整百分数的基期/增长量计算
* 选项差距适中

**例题**

> 判断：基期 463，现期 415，降幅是否超过 10%？

**解题过程**

| **步骤**   | **内容**                             |
| -------- | ---------------------------------- |
| ① 转化判定式  | 降幅超 10% → 现期 \< 基期 × 0.9           |
| ② 错位减速算  | 463 × 0.9 = 463 − 46.3 = **416.7** |
| ③ 比较得出结论 | 415 \< 416.7 → **降幅超过 10%** ✅      |

***

### 2️⃣ 拆分法（精算专用）

**核心要点**

* 把复杂乘数拆成「**整数 + 零头**」，分别相乘再加减
* 避免复杂进位，降低出错率

**适用场景**

* 选项差距小（\<5%）
* 乘数不规整，需要相对精确的计算

**例题**

> 计算：347 × 1.23

**解题过程**

```
347 × 1.23
= 347 × (1 + 0.2 + 0.03)
= 347 + 69.4 + 10.41
= 426.81
```

| **拆分项** | **计算**     | **结果**       |
| ------- | ---------- | ------------ |
| 整数部分    | 347 × 1    | 347          |
| 零头①     | 347 × 0.2  | 69.4         |
| 零头②     | 347 × 0.03 | 10.41        |
| 合计      | —          | **426.81** ✅ |

***

### 3️⃣ 凑整估算法

**核心要点**

* 把数字凑成**整十/整百/好算的数**，先算出近似值
* 再根据**误差方向**微调结果（放大了就调小，缩小了就调大）

**适用场景**

* 选项差距大（>10%）
* 只需判断范围，不需要精算

**例题**

> 计算：592 × 18.3%

**解题过程**

```
≈ 600 × 18% = 108
```

| **调整项**     | **方向**          | **影响**          |
| ----------- | --------------- | --------------- |
| 592 → 600   | 放大 ↑            | 结果偏大            |
| 18.3% → 18% | 缩小 ↓            | 结果偏小            |
| 综合          | 一升一降，误差**部分抵消** | 真实值 ≈ 108（略小） ✅ |

***

## 三、⚠️ 易错提醒

| **方法** | **常见坑**                          |
| ------ | -------------------------------- |
| 错位加减速算 | 固定倍率记混（×0.9 是**减**不是加）；判定题注意比较方向 |
| 拆分法    | 拆分后各项别漏加/漏减；小数点位数要对准             |
| 凑整估算法  | 只凑一边误差会累积；注意“一放一缩可抵消”的技巧         |

***

## 四、📌 做题思考顺序（核心思路）

```
看到乘法计算
    │
    ▼
第一步：看 r（乘数）是否规整？
    ├─ 是（1.1 / 0.9 / 1.2 / 1.5 等）
    │      → ⭐ 错位加减速算（首选！最快）
    │
    └─ 否 → 第二步：看选项差距
              ├─ 差距大（>10%）
              │      → 凑整估算法（快，只定范围）
              ├─ 差距小（<5%）
              │      → 拆分法（稳，要精算）
              └─ 差距适中
                     → 错位/凑整 + 微调，灵活组合
```

### 💡 思考三连问

1. **乘数规整吗？** → 规整就用错位加减，别犹豫
2. **选项差多少？** → 差得多就估，差得少就拆
3. **误差往哪偏？** → 估算后一定要判断真实值偏大还是偏小，防止“算对了却选错”

# 📊 资料分析 · 除法速算 完整笔记（含 5%-30% 全量百化分）

## 【前置步骤：判断选项差距】（做除法必看！）

| **选项特征**          | **差距类型**       | **对策** |
| ----------------- | -------------- | ------ |
| 首位不同；或首位相同、次位差＞首位 | **差距大（>10%）**  | 可大胆估算  |
| 首位相同、次位差＜首位       | **差距小（\<10%）** | 需要精算   |

***

## 【总匹配原则：按增长率 r 选方法】⭐核心决策表

| **r 的范围**        | **首选方法**      | **备用方法**   |
| ---------------- | ------------- | ---------- |
| **r \< 5%**      | 化除为乘法         | —          |
| **5% ≤ r ≤ 30%** | 百化分转乘法（能乘绝不除） | 不凑整 → 截位直除 |
| **r > 30%**      | 截位直除法（兜底）     | —          |

***

## 一、四种方法速查对比表

| **方法**    | **本质原理** | **适用场景**       | **一句话口诀**             |
| --------- | -------- | -------------- | --------------------- |
| **化除为乘**  | 近似公式     | r\<5% 的基期计算    | ÷(1+r) ≈ 减，÷(1−r) ≈ 加 |
| **百化分转乘** | 分数等价替换   | 5%-30%，r 接近标准值 | 能乘绝不除                 |
| **等比放缩**  | 分子分母同缩放  | 分母接近整数；分数比较    | 分母凑整，分子同步             |
| **截位直除**  | 有效数字截取   | 万能兜底，r>30% 或精算 | 分母截位，除到能区分就停          |

***

## 二、逐个方法详解

### 1️⃣ 化除为乘法（r \< 5% 专属）

**核心公式（必背）**

| **类型** | **公式**                |
| ------ | --------------------- |
| ÷(1+r) | A/(1+r) ≈ **A − A×r** |
| ÷(1−r) | A/(1−r) ≈ **A + A×r** |

**适用场景**：小增长率的基期计算，选项差距适中

**例题**

> 现期 4285，增长 3.4%，求基期。

```
4285 ÷ (1 + 3.4%) ≈ 4285 − 4285×3.4% ≈ 4139 ✅
```

⚠️ **注意**：只适用于 |r| \< 5%，r 越大误差越大！

***

### 2️⃣ 百化分转乘法（5% ≤ r ≤ 30% 首选）⭐

**核心要点**

* 把分母 1±r 转化为分数，除法变乘法，**能乘绝不除**
* **结果微调原则**：分母比标准值**大** → 结果略**小**；分母比标准值**小** → 结果略**大**

**📈 增长型对照表（分母 = 1+r）**

| **增长率 r** | **分母 1+r** | **等价分数** | **除法转乘法**      |
| --------- | ---------- | -------- | -------------- |
| 5%        | 1.05       | 21/20    | ×20/21         |
| 6.25%     | 1.0625     | 17/16    | ×16/17         |
| 10%       | 1.1        | 11/10    | ×10/11         |
| 11.1%     | 1.111      | 10/9     | ×9/10          |
| 12.5%     | 1.125      | 9/8      | ×8/9           |
| 14.3%     | 1.143      | 8/7      | ×7/8           |
| 16.7%     | 1.167      | 7/6      | ×6/7           |
| 20%       | 1.2        | 6/5      | ×5/6           |
| 25%       | 1.25       | 5/4      | ×0.8           |
| 28.6%     | 1.286      | 9/7      | ×7/9           |
| 30%       | 1.3        | —        | ❌ 无友好分数 → 截位直除 |

**📉 下降型对照表（分母 = 1−r）**

| **降幅 r** | **分母 1−r** | **等价分数** | **除法转乘法**      |
| -------- | ---------- | -------- | -------------- |
| 5%       | 0.95       | 19/20    | ×20/19         |
| 10%      | 0.9        | 9/10     | ×10/9          |
| 11.1%    | 0.889      | 8/9      | ×9/8           |
| 12.5%    | 0.875      | 7/8      | ×8/7           |
| 14.3%    | 0.857      | 6/7      | ×7/6           |
| 16.7%    | 0.833      | 5/6      | ×1.2           |
| 20%      | 0.8        | 4/5      | ×1.25          |
| 25%      | 0.75       | 3/4      | ×4/3           |
| 28.6%    | 0.714      | 5/7      | ×7/5           |
| 30%      | 0.7        | —        | ❌ 无友好分数 → 截位直除 |

**例题**

> 现期 4192，降幅 19.06%，求基期。

| **步骤**   | **内容**                                               |
| -------- | ---------------------------------------------------- |
| ① 找接近标准值 | 19.06% ≈ 20% → ÷0.8 ≈ ×1.25                          |
| ② 转乘计算   | 4192 × 1.25 = 5240                                   |
| ③ 误差微调   | 真实分母 0.8094 **大于** 0.8 → 结果略**小**于 5240 ≈ **5180** ✅ |

***

### 3️⃣ 等比放缩法（分母凑整辅助）

**核心要点**

* 分子分母按**相同比例**缩放，分数值不变
* 把分母凑成整数 / 好算的数，简化计算

**适用场景**：5%-30% 区间，分母接近整十数；多用于**分数比较**（精算速度弱于截位直除）

**例题**

> 4192 ÷ 0.8094

```
分母缩小约 1% 凑成 0.8，分子同步缩小 1%
≈ 4150 ÷ 0.8 = 5187.5 ✅
```

***

### 4️⃣ 截位直除法（万能兜底）🛡️

**核心要点**

* **分母截有效数字，分子不动**
* 除到能区分选项就停，不用除完

| **选项差距**   | **分母截位**  |
| ---------- | --------- |
| 差距大（>10%）  | 截 **2** 位 |
| 差距小（\<10%） | 截 **3** 位 |

**适用场景**：所有除法题型，尤其 r>30%、选项差距小的精算

**例题**

> 31325 ÷ 0.9266，选项差距小

```
分母截 3 位：0.9266 → 0.927
31325 ÷ 927 ≈ 33.8xx（即 338xx）✅
```

***

### 5️⃣ 多步除法（连除/叠除）

**核心要点**

* 先**交叉约分**整理成 (A×D)/(B×C)，再分别截位计算

**适用场景**：基期比重、基期倍数、平均数的倍数等题型

**例题**

```
1234/1.12 ÷ 2345/1.08
= (1234 × 1.08)/(2345 × 1.12)
≈ 0.52 ✅
```

***

## 三、⚠️ 易错提醒

| **方法** | **常见坑**                                                   |
| ------ | --------------------------------------------------------- |
| 化除为乘   | 只能用于 r\<5%；r 大了误差失控                                       |
| 百化分    | 别记混方向：÷0.8 是 ×1.25（变**大**），÷1.25 是 ×0.8（变**小**）；30% 无友好分数 |
| 等比放缩   | 分子分母必须**同方向同比例**缩放                                        |
| 截位直除   | 只截分母不截分子；差距判断错会导致截位不够精                                    |
| 多步除法   | 交叉约分别搞反：除以分数 = 乘它的倒数                                      |

***

## 四、📌 做题思考顺序（核心思路）

```
看到除法计算
    │
    ▼
第一步：看选项差距
    （决定能估多粗：差距大→2位截/大胆估；差距小→3位截/精算）
    │
    ▼
第二步：看 r 落在哪个区间
    ├─ r < 5%
    │      → 化除为乘（A ÷ (1+r) ≈ A − A×r）
    │
    ├─ 5% ≤ r ≤ 30%
    │      ├─ r 接近标准值（10%、12.5%、20%…）
    │      │      → ⭐ 百化分转乘法（能乘绝不除）
    │      │         算完记得按真实分母微调方向！
    │      ├─ 分母接近整数 → 等比放缩
    │      └─ 都不凑整 → 截位直除
    │
    └─ r > 30%
           → 截位直除兜底
    │
    ▼
第三步：多步除法？
    → 先交叉约分成 (A×D)/(B×C)，再按上面规则逐个处理
```

### 💡 思考三连问

1. **选项差多少？** → 决定估算精度（截几位）
2. **r 是多少？** → 决定用哪条路径（\<5% 化乘 / 5-30% 百化分 / >30% 直除）
3. **结果偏哪边？** → 百化分和估算后，必须判断真实值偏大还是偏小，防止选错

# 📊 资料分析 · 分数比较速算 完整笔记

> ⭐ 方法按**优先级排序**，优先用前面的，**能秒杀不计算**！

## 一、六种方法速查对比表

| **优先级** | **方法**       | **适用场景**        | **一句话口诀**             |
| ------- | ------------ | --------------- | --------------------- |
| ①       | **一大一小直接判**  | 分子分母反向变化        | 分子大且分母小 → 分数大         |
| ②       | **直除首位法**    | 绝大多数比较（基础法）     | 同截位，商大者大              |
| ③       | **倍数比较法**    | 同大同小、倍数明显       | 分子倍数大→大分数大；分母倍数大→大分数小 |
| ④       | **化同法**      | 分子或分母有明显倍数关系    | 凑分子/凑分母相同，比另一部分       |
| ⑤       | **差分法**      | 两分数非常接近         | 差分数大，大分数大             |
| ⑥       | **放缩法/盐水思维** | 接近基准值（25%、50%…） | 混进浓度大的，整体变大           |

***

## 二、逐个方法详解

### 1️⃣ 一大一小直接判（秒杀级，优先看）⚡

**核心要点**

* 分子大、分母小的分数，值**一定更大**
* 口诀：**分子大且分母小 → 分数大**

**适用场景**：分子分母反向变化（一个分子大、分母反而小），直接出答案

**例题**

> 比较 357/12 和 298/15

| **步骤** | **内容**                       |
| ------ | ---------------------------- |
| ① 看分子  | 357 > 298 ✅ 前项大              |
| ② 看分母  | 12 \< 15 ✅ 前项小               |
| ③ 结论   | 357/12 **>** 298/15（秒杀，不用算）✅ |

***

### 2️⃣ 直除首位法（最通用，基础法）🛡️

**核心要点**

* 分子分母同截前 2-3 位，直接除看**商的首位/前两位**
* 谁商大谁就大

| **选项/分数差距** | **截位**    |
| ----------- | --------- |
| 差距大         | 截 **2** 位 |
| 差距小         | 截 **3** 位 |

**例题**

> 比较 2389/134 和 3105/187

```
2389 ÷ 134 ≈ 17.x
3105 ÷ 187 ≈ 16.x
→ 17.x > 16.x → 前者大 ✅
```

***

### 3️⃣ 倍数比较法（心算比大小）🧠

**核心要点**分别看分子、分母的变化倍数：

* **分子倍数 > 分母倍数** → 大分数更大
* **分母倍数 > 分子倍数** → 大分数更小

**口诀：分子倍数大，分数就大；分母倍数大，分数就小**

**适用场景**：两个分数同大同小，倍数关系明显，心算即可

**例题**

> 比较 85/320 和 120/480

| **步骤** | **内容**                       |
| ------ | ---------------------------- |
| ① 分子倍数 | 85 → 120，约 **1.4** 倍         |
| ② 分母倍数 | 320 → 480，**1.5** 倍          |
| ③ 判断   | 分母倍数（1.5）> 分子倍数（1.4）→ 大分数反而小 |
| ④ 结论   | 85/320 **>** 120/480 ✅       |

***

### 4️⃣ 化同法（凑分子/凑分母相同）

**核心要点**把一个分数的分子或分母放大/缩小，化成与另一个**相同或接近**，再比较另一部分：

* 分母相同 → 分子大的分数大
* 分子相同 → 分母小的分数大

**适用场景**：分子或分母存在明显倍数关系

**例题**

> 比较 6/13 和 12/25

```
前项分子 ×2：6/13 = 12/26
分子相同（12 = 12），26 > 25
分母大的分数小 → 12/26 < 12/25
结论：6/13 < 12/25 ✅
```

***

### 5️⃣ 差分法（极接近分数专用）🎯

**核心要点**适用：一个分数分子分母都大于另一个（同大同小且**非常接近**）

| **步骤** | **操作**                                  |
| ------ | --------------------------------------- |
| ① 作差   | 大分数 − 小分数 = **差分数**（分子减分子、分母减分母）        |
| ② 比较   | 差分数 与 **小分数** 比大小                       |
| ③ 结论   | 差分数**大** → 大分数**大**；差分数**小** → 大分数**小** |

**口诀：差分数大，大分数大；差分数小，大分数小**

**例题**

> 比较 7/13 和 9/17

| **步骤** | **内容**                                  |
| ------ | --------------------------------------- |
| ① 定大小  | 大分数 9/17，小分数 7/13                       |
| ② 作差   | (9−7)/(17−13) = 2/4 = **1/2**           |
| ③ 比较   | 1/2 \< 7/13（7/13 过半，1/2 恰好一半）→ 差分数**小** |
| ④ 结论   | 大分数小 → **9/17 \< 7/13** ✅               |

***

### 6️⃣ 放缩法/盐水思维（进阶估算）

**核心要点**

* 分子分母**同比例缩放**，分数值不变
* 把分数拆成“**基准比例 + 零头**”，用混合浓度思路判断

**口诀：混进浓度大的，整体变大；混进浓度小的，整体变小**

**适用场景**：分数接近某一基准值（如 25%、50%），拆分后快速判断范围

**例题**

> 比较 201/885 和 236/1030

| **步骤**     | **内容**                                               |
| ---------- | ---------------------------------------------------- |
| ① 前项对标 25% | 885 × 25% = 221.25；201 \< 221.25 → **小于 25%**（差 20）  |
| ② 后项对标 25% | 1030 × 25% = 257.5；236 \< 257.5 → **小于 25%**（差 21.5） |
| ③ 判断       | 两者都小于 25%，比较偏离程度 → 后者离 25% 相对更近                      |
| ④ 结论       | 201/885 **\<** 236/1030 ✅                            |

***

## 三、⚠️ 易错提醒

| **方法**  | **常见坑**                   |
| ------- | ------------------------- |
| 一大一小直接判 | 必须是“分子大且分母小”才成立，同大同小不能用   |
| 直除首位法   | 分子分母要**同截位**（都截2位或都截3位）   |
| 倍数比较法   | 倍数算反：是“大分数”跟“小分数”比，别搞混基准  |
| 化同法     | 分子放大几倍，分母必须**同步**放大，分数才不变 |
| 差分法     | 差分数是和**小分数**比，不是和大分数比     |
| 放缩法     | 基准值选错会绕晕，先估算分数大概在哪个区间     |

***

## 四、📌 做题思考顺序（核心思路）

```
看到两个分数比较
    │
    ▼
第一步：分子分母反向吗？（一大一小）
    ├─ 是 → ⭐ 直接判，秒杀！（不用算）
    │
    └─ 否（同大同小）→ 第二步：倍数关系明显吗？
              ├─ 分子/分母倍数一眼看出
              │      → 倍数比较法（心算）或化同法
              │
              └─ 倍数不明显 → 第三步：分数接近吗？
                        ├─ 差距明显 → 直除首位法（截位除）
                        ├─ 非常接近 → 差分法
                        └─ 接近基准值（25%、50%…）
                                 → 放缩法/盐水思维
```

### 💡 思考三连问

1. **反向吗？** → 分子大分母小，直接出答案
2. **倍数明显吗？** → 同大同小先比倍数，心算定大小
3. **接近吗？** → 差距大直除，非常接近用差分，贴基准值用盐水思维

> ⚠️ **兜底原则**：任何方法卡壳，直除首位法永远可用！
